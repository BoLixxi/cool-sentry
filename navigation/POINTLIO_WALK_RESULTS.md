## 解释和边界

本次证明传感器到局部里程计及 RViz 显示链路能在手持移动时持续工作。
这里的 2.8 cm 是起终估计位置差，未用外部测量装置验证，不能当作绝对定位精度。
用户凭感觉恢复朝向，因此 10.87° 可能包含实际放置角度差，不能直接认定为算法漂移，也不能认为朝向精度已通过。
本次最大估计位移只有 0.423 m，尚未完成可测量的 1 m 路径验证。
最后 5 秒的位置变化也可能包含手放稳过程，不能等同纯静止漂移。
未验证全局地图重定位、回环修正、Nav2 规划或底盘运动。

原始记录位于 navigation/log/walk_20261013/：odometry.csv、status.json、result.json、livox.log、pointlio.log、rviz.log。
log 目录不上传 Git；本文件保留关键结果供 GitHub 交接。

## 再做一次可测量的往返

1. 在桌面或地面标记支架的固定落点和朝向线，拍照或测量起点位置。雷达牢固固定在刚性支架上，网线留余量。
2. 启动下方命令，保持静止；status.json 中 ready=true 后才开始移动，约需十余秒。
3. 测量并标记约 1 m 远的终点，缓慢移动过去，停稳；原地缓慢转约 90° 再转回，避免剧烈摇晃。
4. 返回原落点，对齐朝向线，放手静止 10 秒，再结束。观察墙面是否重影、轨迹是否跳变。
5. 对比估计位移与实测 1 m 距离、起终位置和朝向差。若有异常，保存日志及画面，先排查安装、遮挡、网络和环境几何。

```bash
cd /home/xiaoli/Desktop/sp_vision_25-main
source navigation/deploy/setup_mid360.bash
# 每轮使用新目录；默认最长 10 分钟，期间不会发送底盘速度
python3 navigation/tests/pointlio_rviz_session.py \
  --output navigation/log/walk_second --seconds 600
```

另一个终端查看初始化状态：

```bash
cat /home/xiaoli/Desktop/sp_vision_25-main/navigation/log/walk_second/status.json
```

返回并静止完成后，在运行脚本的终端按 Ctrl+C，或关闭 RViz，或另一个终端执行：

```bash
touch /home/xiaoli/Desktop/sp_vision_25-main/navigation/log/walk_second/finish
```

脚本会正常停止三组进程并生成 result.json。终端启用软件流控时，Ctrl+S 暂停输出、Ctrl+Q 恢复输出，都不能代替停止进程。
RViz 鼠标左键拖动旋转视角，中键拖动平移，滚轮缩放；Fixed Frame 为 camera_init。
配准点云保留最近 5 秒，黄色路径来自 /path；黄色线是估计轨迹，不是规划路径。
