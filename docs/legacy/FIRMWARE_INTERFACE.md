# 电控接口核对

核对目录：`/media/xiaoli/Data/RM/sentry-master/sentry-master`。

## 当前问题

1. `Application/ins_task.c` 的 `IMU_SendData` 使用 `%.*s` 发送二进制四元数。精度 19 只是字符串最大长度，遇到零字节仍停止；应使用固定长度的 `HAL_UART_Transmit`。发送帧实际为 19 字节，最后一字节是前 18 字节的累加和。
2. `Gimbal_ParseCommand` 的字段偏移落后一字节。正确偏移为 control=3、shoot=5、yaw=7、pitch=11；float 应用 `memcpy` 解码，避免未对齐和别名问题。
3. `Src/usart.c` 有接收完成回调，但未找到首次启动 USART1 接收的调用。现有固定 16 字节分组也没有丢字节后的重同步。
4. 解析函数只有局部变量和示例注释，没有控制云台或拨弹盘。云台目前用遥控器目标，角度单位为度；视觉发送弧度，接入时还要核实轴方向、零点和 yaw 连续角处理。

因此，这份源码不能证明已有稳定的双向自瞄通信；此前板上运行的固件可能与目录中的源码不同。

## 已准备的电控修正

`firmware/usart_protocol_fix.patch` 是供核对的补丁，尚未应用到外部电控目录，也未烧录。该补丁现在与本文一起归档在 `docs/legacy/`：

- 固定发送 19 字节，发送超时 5 ms；115200 波特率下约需 1.65 ms，仍会阻塞 INS 任务，需要后续测量周期抖动，再决定是否改 DMA。
- 修正指令偏移、类型读取，检查命令 ID、开关值和有限角度。
- 启动单字节接收中断，按帧头、ID、校验重新同步，并在串口错误后重启接收。
- 保存最新解析结果到 `vision_command`，携带接收时间；尚不驱动电机。

补丁的 `Src/usart.c` 部分以 UTF-8 表示；原文件是 GB18030、CRLF，应用前应统一编码并备份，不能直接盲目应用。当前机器没有 ARM 编译器，电控 Keil 工程未编译验证。

控制任务接入时必须在短临界区内复制整个 `vision_command`，因为 `volatile` 不保证多字段快照一致。需要同时满足遥控器启用、有效指令、未超时和机械角度限制。建议先用 100 ms 指令超时；超时或 control=0 必须取消视觉开火并按队伍约定返回遥控/保持模式。摩擦轮、拨弹盘和遥控急停逻辑应共同约束 shoot，不能收到 shoot=1 就直接开火。

## 联调顺序

先重新编译电控，验证 19 字节完整姿态帧和视觉 16 字节指令的解析值，再确认启用开关与角度单位。之后接海康相机检查内外参和轴方向，最后验证控制与射击。源码与虚拟串口检查阶段无需相机；导航字段待队友给出协议后再接入。
